DSH Themes contributors adapted this MIT-licensed plugin to DeepSeek Harness 0.1.3-alpha.1. The complete published 0.6.6 client and host implementation is retained. Chat and trajectory read their official reactive hooks, pending interactions read the session map, and bookmarks use the official store. Loading older history, search, navigation and forks still use the native session controller. The manual npm update check remains informational; it does not install another package. Runtime verification is a separate receipt.
The session area receives a React child according to the Alpha SessionProvider contract, replacing the old render-function child.
