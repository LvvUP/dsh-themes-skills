# DSH Themes Alpha adaptation

Fixed upstream: ZhengQingJing/dsh-session-tree@28e7887a888adf1747e9a35b38b96f1dac233a23 (MIT). Original catalog ID 3029 is retained.

All native lineage projection, duplicate handling, cycle/orphan reporting, bounded rendering, current-family navigation and addressed subagent navigation are preserved. The adapter replaces retired client-runtime declarations with Alpha controller/UI dependencies and mounts its compiled CSS through a disposable Cordis effect. The plugin remains read-only: native DSH Chat creates branches; choosing a tree row only navigates and never rolls back files or tool side effects. No accounts, credentials or external service are needed beyond the existing Harness installation.

The archive has no production dependencies or lifecycle scripts. React and Alpha services are supplied by the host. Offline fixtures cover the lineage algorithm, React rendering and navigation adapters; they are not a real DSH session lifecycle certification.
